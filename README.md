# Tabu / الكلمات الممنوعة

Mindestens 2 Teams mit je mindestens 2 Personen. Der Erklärer und ein Kontrolleur sehen die Karte. Das Team rät. Das Zielwort, seine Übersetzung, Wortteile und die drei verbotenen Wörter in beiden Sprachen sind tabu. Erraten gibt 1 Punkt. Verbotenes Wort oder Überspringen gibt 0 Punkte; dann ist das nächste Team dran.

فريقان على الأقل، وفي كل فريق شخصان على الأقل. يرى الشارح والمراقب البطاقة ويخمن الفريق. يُمنع ذكر الكلمة أو ترجمتها أو جزء منها والكلمات الثلاث الممنوعة باللغتين. التخمين الصحيح يمنح نقطة. الكلمة الممنوعة أو التخطي يمنح صفرًا، ثم يأتي دور الفريق التالي.
